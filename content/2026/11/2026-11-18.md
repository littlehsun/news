## ① AI / LLM / Agents / Developer Tools

### 1. Microsoft 發表 MAI Code 2 與專用資安模型
**摘要｜** Microsoft 在 11/17 Ignite 發表 MAI Code 2、資安專用模型，以及影像與語音模型；宣稱程式碼能力接近競品、成本更低。

**為什麼重要｜** 企業模型選擇不再只看通用聊天，而是依開發、資安等領域分工。

**二階影響｜** 專用模型可能帶動企業模型路由與獨立安全評測。

**我的判讀｜** 效能與成本比較是廠商宣稱，應以相同工作負載驗證。

**來源｜** [Reuters，11/17](https://www.reuters.com/legal/litigation/microsoft-unveils-ai-models-coding-cybersecurity-it-takes-anthropic-openai-2026-11-17/)

### 2. GitHub Copilot Evals 開放公開預覽
**摘要｜** GitHub 11/17 推出 Copilot Evals 公開預覽，可為 Agent、skills、MCP 工具建立可重複測試，並比較變更前後結果。

**為什麼重要｜** Agent 能否穩定完成工作，比單次展示更重要。

**二階影響｜** 團隊可將工具與提示詞更新納入回歸測試。

**我的判讀｜** 評測品質取決於測試案例與判定標準，通過率不是通用能力保證。

**來源｜** [GitHub，11/17](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/)

### 3. Copilot Code Review 加入自適應審查與機密偵測
**摘要｜** GitHub 11/17 公告 Adaptive 依 Pull Request 風險選擇審查深度，另支援跨公開儲存庫脈絡及機密資訊偵測；部分功能仍在預覽。

**為什麼重要｜** 程式碼審查可將資源集中在高風險變更。

**二階影響｜** 審查成本與機密洩漏預防可能納入同一治理流程。

**我的判讀｜** 不能將 AI 審查視為人工安全審查的完全替代。

**來源｜** [GitHub，11/17](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more/)

### 4. MAI Code 2 與 Flash 登入 GitHub Copilot
**摘要｜** GitHub 11/17 宣布 MAI Code 2 與 MAI Code 2 Flash 可供符合資格的 Copilot 使用者選用，依使用量計費，企業管理員可控管模型政策。

**為什麼重要｜** 大型程式庫推理與輕量修改可以選擇不同成本的模型。

**二階影響｜** 開發團隊可能建立以任務難度為基礎的模型選擇規則。

**我的判讀｜** 實際可用性依方案與管理政策而異，不代表所有帳號已開通。

**來源｜** [GitHub，11/17](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot/)

### 5. Copilot CLI 預覽 Microsoft Entra 登入
**摘要｜** GitHub 11/17 公告 Copilot CLI 可透過 Microsoft Entra 登入，支援特定企業託管帳號及 Microsoft 365 Copilot 授權；目前 Windows 與 macOS 支援，Linux 待推出。

**為什麼重要｜** 企業可統一終端機 Agent 的身分與授權治理。

**二階影響｜** 單一登入與稽核政策可能降低分散憑證的維運負擔。

**我的判讀｜** 這是有資格限制的預覽功能，不能推論 Linux 已支援。

**來源｜** [GitHub，11/17](https://github.blog/changelog/2026-11-17-github-copilot-cli-adds-microsoft-entra-sign-in-as-a-preview/)
