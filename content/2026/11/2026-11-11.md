## ① AI / LLM / Agents / Developer Tools

### 1. Gemini 4 Carbon 正式加入 GitHub Copilot

**摘要｜** GitHub 11/10 宣布 Google Gemini 4 Carbon 在 Copilot 正式提供，涵蓋 VS Code、CLI、coding agent 等介面，依供應商定價計費。

**為什麼重要｜** 多模型選擇擴大，企業須比較模型在實際程式碼工作上的能力與成本。

**二階影響｜** 模型政策與預設啟用規則可能增加企業治理負擔。

**我的判讀｜** GitHub 的產品定位不等於獨立效能測試；應用相同程式庫比較完成率、延遲與費用。

**來源｜** [公開來源，2026/11/10](https://github.blog/changelog/2026-11-10-gemini-4-carbon-in-github-copilot/)

### 2. Claude Fable 5.2 加入 Copilot，資料保留政策須留意

**摘要｜** GitHub 11/9 宣布 Claude Fable 5.2 正式提供，供應商初步測試稱較前版減少工具呼叫；一般使用情境需要資料保留以運作安全分類器。

**為什麼重要｜** Agent 模型選型除了能力，也牽涉提示詞與輸出的資料處理條件。

**二階影響｜** 企業可能需要分開管理敏感程式碼與可使用模型清單。

**我的判讀｜** 效能是供應商早期測試，並非第三方驗證；符合條件的企業可申請暫時的零資料保留安排。

**來源｜** [公開來源，2026/11/09](https://github.blog/changelog/2026-11-09-claude-fable-5-5-in-github-copilot/)

### 3. GitHub Actions 執行記錄加入機密掃描預覽

**摘要｜** GitHub 11/9 宣布 Secret Scanning 公開預覽支援掃描工作流程完成後的執行記錄；只涵蓋啟用後的執行，不回溯舊記錄。

**為什麼重要｜** CI 記錄可能包含憑證，即使程式碼本身沒有洩漏。

**二階影響｜** 企業需要將記錄掃描、金鑰輪替與遮罩機制一併納入安全流程。

**我的判讀｜** 預覽版不涵蓋通用或自訂模式及已遮罩的秘密，不能視為完整防護。

**來源｜** [公開來源，2026/11/09](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs/)

### 4. Copilot CLI 的 C++ 語言伺服器自動處理 MSBuild

**摘要｜** GitHub 11/10 公告，Microsoft C++ Language Server 現在內建 MSBuild 編譯指令擷取器，專案開啟時自動建立編譯資料庫。

**為什麼重要｜** 減少 Agent 為了理解大型 C++ 專案而先執行設定技能的步驟。

**二階影響｜** 可降低設定所耗費的 token，並改善定義跳轉與參照搜尋的穩定性。

**我的判讀｜** 主要適用 MSBuild 專案；CMake 與自訂建置系統仍須相應設定。

**來源｜** [公開來源，2026/11/10](https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds/)

### 5. GitHub 將暫停長期不活躍儲存庫的 Dependabot 警示

**摘要｜** GitHub 11/10 公告，自 12/8 起，多數超過一年無活動的儲存庫將暫停 Dependabot 警示，既有警示封存而非刪除。

**為什麼重要｜** 維護者可能誤以為沒有新警示就是沒有弱點。

**二階影響｜** 企業需清查仍在正式環境使用、但儲存庫缺乏活動的相依套件。

**我的判讀｜** 應建立軟體生命週期清單，避免把安全治理完全交給單一平台通知。

**來源｜** [公開來源，2026/11/10](https://github.blog/changelog/2026-11-10-dependabot-alerts-will-pause-on-inactive-repositories/)
